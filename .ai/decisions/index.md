# Project Decisions Log

This folder records the durable decisions taken on this project: what was decided, why, and any consequences worth remembering. Unlike `.ai/rules/` (coding conventions enforced going forward), this log is a chronological history — entries are not edited once written; a changed decision gets a new entry that supersedes the old one.

Read the relevant entries before making changes that touch versioning, release process, or project-wide conventions.
